Projects

  • Language Utility Tool
    • Language Utility Tool is a multilingual Natural Language Processing (NLP) application designed to improve the processing, understanding, and privacy of textual data in English, Hindi, and Marathi. The project integrates three core modules: Abstractive Text Summarization, Text Anonymization, and Multilingual Spell Checking, providing a unified solution for language processing tasks. The Abstractive Text Summarization module generates concise, context-aware summaries by understanding the semantic meaning of the input text rather than simply extracting sentences. The Text Anonymization module protects sensitive information using multiple privacy-preserving techniques, including redaction, pseudonymization, and generalization, enabling secure handling of textual data while preserving its utility. The Spell Checker module detects and corrects spelling errors across English, Hindi, and Marathi, improving the overall quality and readability of text.
  • Movie Recommendation System
    • The Movie Recommendation System is a machine learning application that recommends personalized movies to users by combining Content-Based Filtering and Collaborative Filtering techniques. The hybrid approach leverages both movie attributes and user preferences to improve recommendation accuracy and provide relevant suggestions. The Content-Based Filtering module recommends movies with characteristics similar to those a user has previously liked by analyzing features such as genres, cast, directors, and keywords. The Collaborative Filtering module identifies patterns in user ratings and preferences to recommend movies that users with similar interests have enjoyed. By integrating both approaches, the system addresses the limitations of individual recommendation techniques, enhances personalization, and improves the overall user experience.
  • Personality Detector
    • The Personality Detector is a machine learning application that predicts an individual's personality traits based on their responses to a structured questionnaire. The system presents users with a series of multiple-choice questions designed to capture behavioral patterns, preferences, and decision-making tendencies. Based on the collected responses, a trained machine learning model analyzes the input and classifies the user's personality traits.
